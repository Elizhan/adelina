# С днём рождения, Аделина!

Поздравительный сайт: торт со свечами «19» (задуваются через микрофон или нажатием), конфетти и аплодисменты, открытка с пожеланиями, слайд-шоу из фото и музыка.

## Что внутри

- `index.html` — сама страница
- `img/` — 8 фотографий для слайд-шоу
- `audio/song.mp3` — музыка
- `.nojekyll` — служебный файл для GitHub Pages (пустой, его тоже нужно загрузить)

## Как выложить на GitHub Pages

1. На github.com нажмите **New repository**, придумайте имя (например, `adelina`), выберите **Public** и нажмите **Create repository**.
2. На странице репозитория нажмите **uploading an existing file** (или **Add file → Upload files**).
3. Перетащите в окно всё содержимое папки: `index.html`, `README.md`, папки `img` и `audio`. Папки перетаскиваются целиком.
4. Внизу нажмите **Commit changes**.
5. Откройте **Settings → Pages**. В **Build and deployment** выберите Source **Deploy from a branch**, Branch **main** и **/ (root)**, нажмите **Save**.
6. Через 1–2 минуты сайт откроется по адресу `https://ВАШ-НИК.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

Файл `.nojekyll` на некоторых компьютерах скрыт. Если он не загрузился, сайт всё равно будет работать.

## Важно

- Микрофон работает только по ссылке `https://...github.io/...`. Если открыть `index.html` просто с компьютера двойным щелчком, свечи можно будет задуть только нажатием.
- Музыка включается после первого нажатия на странице: браузеры не дают сайтам включать звук самим.
- Репозиторий публичный, поэтому фото сможет увидеть любой, кто его найдёт. После праздника его можно удалить или сделать приватным (тогда сайт перестанет открываться).
